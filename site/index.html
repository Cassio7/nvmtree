Update checks for npm and Node

With -u, nvmtree asks npm and nodejs.org what is newer, marks deprecated packages and prints the nvm and npm lines to run. It never installs anything. Read the usage guide

Four nvmtree commands. All read-only.

Moves packages to a new Node

Compares two versions and prints the one npm line that installs what the new one lacks.

nvmtree diff 22 24
v22.21.1 → v24.22.0 (default)Only in v22.21.1:  eslint  9.12.0To install the missing packages in v24.22.0:  nvm exec 24.22.0 npm i -g eslint

Finds the versions with a tool

Search by package or by command: which tsc finds typescript in every version.

Prints JSON for your scripts

Add --json to the list, diff or which for one document with a schema version.

nvmtree --json
$ nvmtree --json | jq -r '.versions[].version'24.22.022.21.1$ nvmtree 24 --json | jq '.versions[].packages[].name'"@shopify/cli""pnpm""typescript"$ nvmtree --json | jq .schema_version1

Install nvmtree in one line

The script picks the binary for your system, checks its SHA256 checksum and puts it in ~/.local/bin. Run it again to update.

Pin a release with NVMTREE_VERSION, change the folder with NVMTREE_INSTALL_DIR.

Questions

Anything else is in the README and the --help of each command.

Open an issue on GitHub

Does nvmtree change anything?

No. It reads folders and prints. Updates, installs and cleanups are printed as commands for you to run.

Does nvmtree use the network?

Only with -u. It then asks the npm registry and nodejs.org for newer versions and caches the answers for 6 hours.

Will nvmtree suggest an update my Node can't run?

No. Updates respect each package's engines.node and pin the newest version that runs on that Node.

Can a script read the nvmtree output?

Yes. --json prints one JSON document for the list, diff and which.
